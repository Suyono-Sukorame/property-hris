## Brand & Style

This design system delivers an authoritative, high-precision corporate management environment crafted for enterprise property development. Drawing inspiration from modern high-density SaaS interfaces and architectural governance, the visual tone blends operational discipline with structural clarity.

The aesthetic combines clean corporate minimalism with nuanced data-density:
- **Tone:** Authoritative, structured, architectural, and highly dependable.
- **Audience:** C-suite executives, project site administrators, HR leaders, and property division managers navigating complex payroll, attendance, and staffing requirements.
- **Emotional Response:** Inspires confidence, efficiency, and clarity when processing complex administrative actions across corporate offices and active property construction sites.
- **Visual Style:** Minimalist, data-first corporate software. White layered surfaces sit on pale architectural grounds, defined by hairline boundaries, crisp micro-typography, and restrained, high-value jade accents.

## Colors

The palette establishes an elevated corporate real estate aesthetic anchored by deep, architectural jade tones paired with disciplined slate neutrals.

- **Primary (`#0F766E`):** Represents structural stability, growth, and governance. Applied to primary actions, selected navigation states, active KPI indicators, and authoritative touchpoints.
- **Secondary (`#334155`):** Slate structural neutral used for structural icons, table headings, card frame contours, and secondary buttons.
- **Tertiary (`#D97706`):** Amber accent reserved for caution states, pending approvals, and urgent audit notices.
- **Neutral (`#0F172A`):** Deep architectural navy-slate for primary data values and headlines, preventing pure-black harshness while ensuring rigorous accessibility.
- **Surfaces:** Canvas utilizes `#F8FAFC` (Slate-50) for spatial relief, contrasting with `#FFFFFF` card containers and subtle `#E2E8F0` structural divider borders.
- **Status & Badges (Enterprise HR Lifecycle):**
  - *Aktif / Hadir / Disetujui / Dibayar:* Soft jade background (`#ECFDF5`), deep jade text (`#065F46`), subtle hairline border (`#A7F3D0`).
  - *Terlambat / Draft:* Soft amber background (`#FFFBEB`), amber text (`#92400E`), amber border (`#FDE68A`).
  - *Cuti / Nonaktif:* Muted slate background (`#F1F5F9`), slate text (`#475569`), slate border (`#CBD5E1`).
  - *Ditolak / Krisis:* Crimson background (`#FEF2F2`), crimson text (`#991B1B`), crimson border (`#FECACA`).

## Typography

The typographic hierarchy pairs `Manrope` for structured, architectural headlines with `Public Sans` for high-clarity data grids, legal documentation, and employee records.

- **Headlines (Manrope):** Clean geometric letterforms deliver high-end presence across administrative section headers, module dashboards, and organizational overview screens.
- **Body & Tabular Data (Public Sans):** Chosen for its neutral, highly legible rhythm, ensuring uncompromised readability across complex payroll slips, timecard logs, and enterprise filters.
- **Numeric Handling:** Tabular figures (`tnum`) must be enforced for numeric data across payroll figures (*Penggajian*), total staff counts (*Data Karyawan*), and real-time attendance logs (*Absensi*).
- **Scale Rules:** Display sizes dynamically collapse using dedicated mobile breakpoints to preserve viewport efficiency on field inspection tablets and mobile devices.

## Layout & Spacing

The layout model utilizes a fluid 12-column corporate grid with responsive gutters and compact element rhythms, optimized for enterprise density.

- **Grid Architecture:** 12-column grid for desktop views (>1024px), transitioning to an 8-column layout for tablets (768px-1023px) and a single-column reflow for mobile devices (<768px).
- **Fixed Dimensions:** Navigation sidebar maintains a fixed structural width of 260px on desktop to provide persistent access to core modules (*Data Karyawan, Absensi, Penggajian, Laporan, Pengaturan*).
- **Density Controls:** Component internal padding uses an 8pt modular scale:
  - High-density data tables and lists adhere to `space-xs` and `space-sm` vertical padding.
  - KPI overview metrics, charts, and modal dialogs utilize `space-md` to `space-lg`.
- **Canvas Margins:** Fixed desktop viewport retains a `margin` of `2rem` (32px), reducing to `1rem` (16px) on mobile viewports to maximize data surface area.

## Elevation & Depth

Visual hierarchy relies on structural hairline borders, crisp surface layering, and micro ambient shadows rather than dramatic drop shadows.

- **Base Canvas:** `#F8FAFC` serves as the foundation.
- **Card Containers:** Pure white (`#FFFFFF`) with a continuous 1px perimeter border of `#E2E8F0` (Slate-200).
- **Shadow Profile:** Soft, multi-layered diffuse shadows using cold slate-navy color values:
  - *Level 1 (Cards, Data Sections):* `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.04)`
  - *Level 2 (Popovers, Filter Menus, Dropdowns):* `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)`
  - *Level 3 (Modals, Slide-overs, Approval Dialogs):* `0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`
- **Hover Transitions:** Cards lift minimally; interaction is confirmed primarily by border shifts from `#E2E8F0` to `#CBD5E1` combined with subtle 1px vertical translation.

## Shapes

The design system incorporates roundedness level `2`, generating an authoritative yet modern software interface.

- **Base Radius (0.5rem / 8px):** Applied to buttons, inputs, badge containers, and internal element groupings.
- **Container Radius (1rem / 16px):** Applied to operational cards, metric widgets, analytics tiles, and main content sheets (`rounded-lg`).
- **Surface Modal Radius (1.5rem / 24px):** Reserved for large overlay panels, document review sheets, and onboarding modals (`rounded-xl`).
- **Pill Exceptions:** User status badges (*Aktif, Cuti, Nonaktif, Hadir, Terlambat, Draft, Disetujui, Dibayar*) utilize a full pill radius (`rounded-full`) to clearly distinguish statuses from interactive square buttons and input controls.

## Components

### Buttons
- **Primary:** Solid `#0F766E` background, `#FFFFFF` text, subtle top highlight border, hover state `#115E59`.
- **Secondary:** White background, 1px border `#E2E8F0`, text `#334155`, hover state `#F8FAFC`.
- **Destructive:** White background, 1px border `#FECACA`, text `#DC2626`, hover state `#FEF2F2`.
- **Metrics:** Heights are strictly set to 36px for default controls and 32px for compact table action triggers.

### Badges & Status Indicators
- Pill-shaped badges (`rounded-full`) with uppercase tracking (`letterSpacing: "0.03em"`).
- Micro dot indicator (6px circle) preceding the text for rapid visual scanning across tabular lists:
  - *Aktif / Disetujui:* Jade dot (`#0F766E`), background `#ECFDF5`, text `#065F46`.
  - *Terlambat / Draft:* Amber dot (`#D97706`), background `#FFFBEB`, text `#92400E`.
  - *Cuti / Nonaktif:* Slate dot (`#64748B`), background `#F1F5F9`, text `#475569`.

### Input Fields & Controls
- **Text & Select Fields:** Height 38px, background `#FFFFFF`, border 1px solid `#CBD5E1`, text `#0F172A`, placeholder `#94A3B8`.
- **Focus State:** 2px ring in `#0F766E` with 20% opacity and 1px border `#0F766E`.
- **Checkboxes & Radios:** 16px dimension, border `#CBD5E1`, selected background `#0F766E` with crisp white check/circle indicator.

### Data Tables (*Data Karyawan, Absensi, Penggajian*)
- **Header:** Height 40px, background `#F8FAFC`, uppercase label text `#475569`, border-bottom 1px solid `#E2E8F0`.
- **Row:** Height 52px, alternating hover background `#F8FAFC`, border-bottom 1px solid `#F1F5F9`.
- **Pagination:** Clean bottom bar with subtle page controls and clear record range summaries.

### Cards & KPI Tiles
- White canvas surface, 1px border `#E2E8F0`, padding `1.5rem`.
- KPI Tiles feature a subtle top border highlight (2px solid `#0F766E`) when active or selected, with compact secondary trend indicators (+/- percentages).

### Domain-Specific Components
- **Employee Identity Card:** Compact profile avatar paired with job code, division badge, and quick-action menu.
- **Approval Workflow Matrix (*Persetujuan*):** Step-by-step progress trail showing submission, review, and final HR sign-off states.
- **Pay Slip Sheet (*Slip Gaji*):** High-density split ledger showing basic pay, site allowances, deductions, and net payouts with tabular numeral alignment.
